# Book Price Scraper

Python script that extracts book titles and prices from 
books.toscrape.com and saves the results into an Excel file.

Practice project demonstrating scraping techniques: pagination, 
error handling with try/except, and data export.

## Technologies
- Python
- requests
- BeautifulSoup4
- openpyxl
- time
- random

## How to run it
1. Install dependencies: `pip install requests beautifulsoup4 openpyxl`
2. Run: `python scraper.py`
3. This generates `Books.xlsx` with the results
